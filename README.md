# CareDroid Emergency OS

CareDroid Emergency OS is a React/Vite Emergency Department operating surface with a NestJS backend, focused on whiteboard flow, EMS intake, referrals, capacity pressure, clinical tools, shift context, and human-reviewed AI support.

The repository keeps one documentation source of truth:

- [`docs/CARE_DROID_MASTER_PLATFORM_INVENTORY.md`](docs/CARE_DROID_MASTER_PLATFORM_INVENTORY.md)

That master file now contains the platform inventory, architecture and route summaries, feature/tool/calculator status, AI/RAG/MoE/tool-calling strategies, governance/security/audit guidance, roadmap, and the legacy markdown corpus that used to be split across many separate documentation files.

## Documentation policy

- Keep this README as the short entry point only.
- Put all platform documentation updates in `docs/CARE_DROID_MASTER_PLATFORM_INVENTORY.md`.
- Do not add new standalone markdown reports unless the master inventory is intentionally being split again.
