# Emergency OS
Emergency Department Operating System for
high-pressure EDs with small clinical teams.

Built for: ~100 patients/day · teams under 10
Primary screen: Emergency Whiteboard
Stack: React/Vite/TypeScript frontend with React Router and Zustand; NestJS/Express backend with TypeORM, Mongoose, PostgreSQL/SQLite, and Redis dependencies.

## Getting started
npm install && npm run dev
Navigate to: http://localhost:3000

The product is now one thing.
One name. One purpose. One codebase.
