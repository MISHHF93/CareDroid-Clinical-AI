# Training & Onboarding Guide

## Recommended Path

1. Start with `docs/PRODUCT_DISCOVERY_REPORT.md`.
2. Read your role manual in `docs/users`.
3. Walk through `docs/workflows/patient-journey.md`.
4. Practice the three-minute response workflow.
5. Use in-app Help with `?` or the Guide button.

## Training Scenarios

Reception walk-in, EMS conversion, triage acuity, reassessment breach, capacity surge, referral delay, discharge documentation, and shift handoff.
