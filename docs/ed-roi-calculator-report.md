# ED ROI Calculator Report

## Goal

Create an ROI estimator that helps sales and onboarding teams show the measurable value of the Emergency Workspace before a hospital connects live integrations.

The estimator should support discovery calls, demo tenant walkthroughs, onboarding, and pilot planning.

## Inputs

The estimator collects four simple hospital assumptions:

- Annual ED volume.
- Physician count.
- Nursing count.
- Average assessments per day.

## Outputs

The estimator returns:

- Estimated time saved: projected hours saved from standardized assessments, calculator routing, protocol retrieval, workflow launch, and AI Copilot guidance.
- Workflow efficiency: an estimated efficiency lift based on ED volume, daily assessment load, and available clinical staff.
- Adoption potential: a simple low, medium, or high signal that sales and onboarding can use to frame rollout depth.

## Sales Use

Sales can use the estimator to:

- Turn discovery data into a value conversation.
- Compare the current scattered workflow against a workspace-driven ED operating model.
- Show why the Emergency Analytics MVP should track assessments completed, calculators used, protocol retrievals, workflow launches, AI requests, and simulation completion.
- Identify whether the prospect should start with Emergency Flow Starter, Demo Mode, or a deeper onboarding pilot.

## Onboarding Use

Onboarding can use the estimator to:

- Set baseline expectations before implementation.
- Identify which roles should join the first walkthrough.
- Choose which demo workflows to emphasize.
- Explain how pilot analytics will later validate or adjust the estimate.

## Acceptance

The ED ROI estimator is ready when:

- The four inputs are editable without integrations.
- The outputs show estimated time saved, workflow efficiency, and adoption potential.
- The estimator is clearly positioned for sales and onboarding.
- The output remains an estimate, not a clinical quality claim or guaranteed financial return.
