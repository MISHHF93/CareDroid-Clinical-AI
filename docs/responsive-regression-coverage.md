# Responsive Regression Coverage

## Automated Coverage

The responsive regression inventory covers core clinical, operations, SaaS, governance, and tool routes through Vitest route smoke tests and the Playwright responsive QA matrix.

## Manual visual checks

Manual visual checks should be performed for 320, 360, 390, 412, 768, 1024, 1280, and 1440 pixel widths.

Playwright coverage is the primary automated browser validation path for responsive behavior. Manual checks focus on sidebar drawer behavior, command launch, tool grids, calculator forms, dashboard cards, and operations maps.
