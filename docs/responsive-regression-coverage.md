# Responsive Regression Coverage

This document records the browser-based responsive QA coverage for the TypeScript platform.

## Automated Coverage

Playwright covers the responsive page matrix across mobile-width, tablet, desktop, and wide desktop viewports. The matrix starts at 320px and includes common phone, tablet, desktop, zoom, and browser combinations.

## Manual Visual Checks

Manual visual checks should focus on route chrome, clinical tool forms, calculator layouts, dense whiteboard states, dialog overflow, and navigation behavior at the smallest phone widths before release.
