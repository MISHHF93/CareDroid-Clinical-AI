Scoring contract

How to read this artifact

The score is a decision aid. It is deliberately conservative where evidence stops.

Evidence rules

Each category receives whole points up to its weight. Credit stops at the strongest evidence actually found.

  • Implemented is not the same as internally tested.
  • Internally tested is not the same as operationally verified.
  • Synthetic fixtures and self-reported signals do not establish external validity.
  • Legal, clinical-safety, security, and red release gates cannot be averaged away.
  • Re-score on a named release or when linked exit evidence changes.
