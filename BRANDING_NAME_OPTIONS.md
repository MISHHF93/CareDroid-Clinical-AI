# CareDroid — Alternative Branding Name Options

**Why this exists:** the `caredroid.com`-style domain isn't available, so this is a
brainstorm of alternatives — close phonetic spellings of "CareDroid" plus fresh
names in the same "clinical AI / emergency care" territory. None of these have
been checked for domain availability or trademark conflicts yet — treat this as
a shortlist to run through a domain registrar and a trademark search (e.g.
USPTO TESS) before committing to any of them.

Legend: 🔊 = sounds like "CareDroid" · 🩺 = clinical/medical-coined · ⚡ = short & punchy

## Suggested next steps

- **Shortlist 8–10** you like best from across categories 1, 4, and 7 (those
  read as the most distinct while staying closest to the current brand feel).
- Check `.com`/`.ai`/`.io` availability for each (a registrar bulk-search tool
  makes this fast — 10 names in one pass).
- Run a quick USPTO TESS trademark search on the survivors, especially against
  existing health-tech/EHR companies.
- Sanity-check pronunciation and spelling-from-memory with a few people outside
  the project — the whole point of a phonetic variant is that people can find
  it again without seeing it written down first.
